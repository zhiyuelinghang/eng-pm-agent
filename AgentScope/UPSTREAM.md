# AgentScope 上游基线

- 核心版本：AgentScope `v2.0.5`
- 上游提交：`999f64db8126f2ded2c9271505d384b911c37943`
- 核心来源：上游仓库的 `src/agentscope`
- Web UI 来源：同一版本的 `examples/web_ui`

## 已选择性回移的上游提交

- `cba9d48`：模型、Embedding 与 TTS 适配器复用 SDK 客户端。
- `c613a86`：增加 `on_check_permission` 权限检查中间件钩子；本地自动权限审核员已迁移到该钩子。
- `27b6a0d`：使用 O(n) 流式响应累积器，避免长响应重复拼接造成性能退化。
- `698297b`：避免外部工具等待结果时被中断后重复发送工具结果开始事件。

这些提交来自 `v2.0.5` 之后的上游主分支，但当前核心版本仍保持
`v2.0.5`，并未整体切换到未发布版本。

## 本地定制

- 智能体可协同范围：全部、指定智能体、禁用。
- 工具组装阶段只向智能体暴露允许协同的智能体。
- 邀请执行阶段重新读取配置，防止配置变更后的陈旧调用。
- Web UI 增加协同智能体配置面板、中文文案、默认连接信息和五位数端口。
- 凭证增加“自定义（OpenAI 兼容）”，按凭证维护自动发现、手动添加和移除模型目录，并支持最小真实调用测试。
- 开发存储使用官方 `AsyncSQLAlchemyStorage`、SQLite 和 Alembic。
- Alembic 配置仅使用 ASCII 注释，以兼容中文 Windows 的默认 GBK 配置读取。
- PowerShell 暂时在管理端与业务端全局禁用；工具组装末端会再次过滤，防止
  工作区、扩展工具工厂或中间件意外重新暴露。后续升级不得直接恢复，只有
  完成独立代码执行沙箱方案评审后才能重新讨论。

后续升级时先同步对应上游版本，再逐项回放和验证上述本地定制。
