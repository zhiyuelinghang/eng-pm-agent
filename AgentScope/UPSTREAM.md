- 代码基线：官方 `v2.0.5`，选择性集成官方 `v2.0.6`、`v2.0.7`
  的适用修复
- 当前对照上游：官方 `main` 快照
  `a40487a754ab11ea09616c3ceb65a6b0f1b6140a`；本地版本仍以
  `v2.0.7` 为基线，按需回移
  `v2.0.7.post1` 及后续修复
- 核心来源：上游仓库的 `src/agentscope`
- Web UI 基线：官方 `v2.0.5` 的 `examples/web_ui`，持续保留本地适配，
  未整体覆盖为官方 `v2.0.7` 界面

- `c613a86`：增加 `on_check_permission` 权限检查中间件钩子；本地自动权限审核员已迁移到该钩子。
- `27b6a0d`：使用 O(n) 流式响应累积器，避免长响应重复拼接造成性能退化。
- `698297b`：避免外部工具等待结果时被中断后重复发送工具结果开始事件。
- `0cd19d7`：保留显式传入的模型中断原因，避免中断被错误报告为完成。
- `7be0da0`：工具流一旦出现错误，不再被后续中断或拒绝状态覆盖。
- `662ebaa`：按完整 Reasoning-Acting 回合计算迭代次数，避免工具调用将
  `max_iters` 预算重复消耗。
- `3d2fca3`：修复同一回复包含多个待确认工具时的消息复用、重复提交、
  失败重试和子智能体确认卡片推进；Web UI 部分已适配本地消息气泡布局。

`v2.0.6` 阶段采用兼容性回移方式，没有整体
引入官方该版本的 Hub、渠道、工作区文件浏览和 Web UI 重构。

## 本地定制

- 智能体可协同范围：全部、指定智能体、禁用。
- 工具组装阶段只向智能体暴露允许协同的智能体。
- 邀请执行阶段重新读取配置，防止配置变更后的陈旧调用。
- Web UI 增加协同智能体配置面板、中文文案、默认连接信息和五位数端口。
- 凭证增加“自定义（OpenAI 兼容）”，按凭证维护自动发现、手动添加和移除模型目录，并支持最小真实调用测试。
- 平台存储使用本地适配的 `AsyncSQLAlchemyStorage`、PostgreSQL 和
  Alembic，并通过独立 schema 隔离 AgentScope 数据。
- Alembic 配置仅使用 ASCII 注释，以兼容中文 Windows 的默认 GBK 配置读取。
- PowerShell 暂时在管理端与业务端全局禁用；工具组装末端会再次过滤，防止
  工作区、扩展工具工厂或中间件意外重新暴露。后续升级不得直接恢复，只有
  完成独立代码执行沙箱方案评审后才能重新讨论。

后续升级时先同步对应上游版本，再逐项回放和验证上述本地定制。

避免只搬入依赖而没有可用产品闭环。

## 2026-08-25 官方 v2.0.7 选择性同步

- 对照标签：官方 `v2.0.7`，提交
  `24bdf4ae43f7ab2b6de892cf35d63fafeed402a8`。
- `ed6ba75e`：解析工具 schema 前解析 PEP 563 延迟注解，并保留
  `Annotated[..., Field(...)]` 携带的约束与说明。
- `9081bd77`：`FunctionTool` 支持直接传入 JSON Schema 或 Pydantic
  模型，便于平台工具精确约束模型调用参数。
- `56eea457`：校验工具二进制结果必须且只能提供 `data`、`url` 之一，
  避免无效事件进入消息流。
- `b6e6906e`：仅按 URL path 判断 MCP SSE 传输，支持带密钥查询参数的
  SSE 地址。
- `cf10eafd`：区分“工具组未激活”和“工具不存在”，让智能体能够先激活
  正确工具组。
- `b22704db`：索引 Worker 被外部取消时同步停止流水线与心跳子任务，
  防止后台任务泄漏。
- `f41cb770`：字典响应对象缺少属性时改为标准 `AttributeError` 语义，
  修复 `hasattr`、带默认值的 `getattr` 和深拷贝兼容性。
- `4e9516f4`：文件读取缓存命中时刷新 LRU 顺序，避免高频使用的缓存被
  提前淘汰。
- `63e64aef`：在模型结束事件、消息累计、最终回复和平台前端流式消息中
  保留提示词缓存读取、创建 token，便于准确统计缓存命中率和模型成本。
- `84918a5f`：允许使用文档声明的最大上下文压缩触发比例 `0.9`。

官方 `e0e43cad`、`13749ff6` 的团队循环和失败回报能力，本地已有
`_team_lifecycle.py`、`_team_messaging.py` 与 ChatService 自动回报机制，
覆盖更完整，因此不重复叠加。钉钉与 SQL 渠道、官方 RAG/Web UI、ReMe
配置、工作空间池及其调度绑定不符合当前平台技术边界；读取工具直接返回
Office/PDF `DataBlock` 会绕开现有资料解析与 WeKnora 链路，也未引入。
追踪 span 写入完整输入消息可能记录项目敏感内容，默认不回移。

本地核心、依赖锁定和启动校验已统一标记为 `v2.0.7`。同步仍坚持逐项
回移，不以覆盖上游目录的方式破坏平台智能体、PostgreSQL、记忆、任务引擎
和企业微信等本地集成。
