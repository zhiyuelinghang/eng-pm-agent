# 建设工程质量安全规范知识库

## 1. JGJ 80-2016 临边防护技术要求

建筑施工高处作业安全技术规范 JGJ 80-2016 第4.2条规定：防护栏杆高度不低于1.2m。临边防护栏杆应设置两道横杆，上杆高度1.2m，下杆高度0.6m。踢脚板高度不低于180mm。栏杆需能承受1000N水平荷载。密目安全网应封闭严密。基坑临边防护应在地面设置挡水墙，高度不低于300mm。

## 2. GB 50656-2011 高处作业分级与防护

建筑施工企业安全生产管理规范 GB 50656-2011 规定：作业高度2m及以上为高处作业，需设置安全网。高处作业人员必须佩戴安全带，安全带应高挂低用。悬空作业应有牢固立足点。高处作业区域下方应设置警戒区。遇6级以上强风禁止露天高处作业。

## 3. JGJ 59-2011 基坑工程安全检查标准

建筑施工安全检查标准 JGJ 59-2011 第3.1条规定：基坑开挖深度超过2m应设临边防护。基坑周边1m内不得堆载。基坑应设置上下通道，通道宽度不小于1m。基坑排水设施应畅通有效。深基坑应进行变形监测，监测频率每日不少于1次。基坑支护结构出现裂缝、变形应立即停工处理。

## 4. 隐患整改闭环管理流程

隐患整改闭环管理流程：
1. 发现隐患
2. 下发整改通知（明确责任人、期限、措施）
3. 责任人整改
4. 监理复核验收
5. 闭合归档

一般隐患限期3天内整改，较大隐患限期1天内整改。逾期未整改的，升级上报项目经理和安全总监。整改完成后48小时内完成复核验收。

## 5. 某项目基坑坍塌事故案例分析

2024年某工地基坑坍塌事故：基坑深度5m，未按方案放坡，临边无防护栏杆。连续降雨导致边坡失稳坍塌，造成2人受伤。

事故原因：
- 未按JGJ 80-2016设置临边防护
- 未进行变形监测
- 排水措施不完善

教训：基坑施工必须严格按方案执行，临边防护不可缺失。

## 6. JGJ 80-2016 安全网设置要求

建筑施工高处作业安全技术规范 JGJ 80-2016 第5条规定：安全网分为平网和立网。平网用于承接坠落人员，立网用于封闭防护。安全网应取得生产许可证和产品合格证。安全网安装后应经检验合格方可使用。安全网使用期间应定期检查，破损或老化应及时更换。密目式安全立网的网目密度不低于2000目/100cm2。
