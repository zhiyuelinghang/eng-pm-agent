工程管理智能体开源优先架构图

重新评估后采用“开源平台为主、少量胶水开发”的路线：NocoBase 承担业务后台，RAGFlow 承担知识库与 RAG，AgentScope/RAGFlow Agent 承担智能体平台，FastAPI 只做必要适配层。

开源平台集成 + 工程业务插件
入口 业务内核 知识入库 检索服务 Agent 编排 数据存储 实线：平台集成主链路 虚线：治理、安全、审计链路
主线变化 不再默认全自研，改为 NocoBase + RAGFlow + AgentScope/LiteLLM 的开源平台组合。
开发边界 我们重点改业务插件、权限同步、RAGFlow 集成、Agent 工具和企业微信等胶水层。
保留红线 知识库和 Agent 可以用平台，但工程业务权限、审批和审计必须有统一边界。
这版是“开源优先”落地方案：先试 NocoBase 管业务后台，RAGFlow 管知识库，AgentScope/RAGFlow Agent 管智能体，LiteLLM 管模型，再按工程业务补插件和适配服务。
