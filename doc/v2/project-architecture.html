知识入库流程
  1. 1用户上传资料，FastAPI 校验身份、项目权限和文件元数据。
  2. 2Celery 提交解析任务，Docling / MinerU 输出 Markdown、JSON、图片和表格结构。
  3. 3切块、摘要、生成 embedding，并写入 PostgreSQL、FTS、pgvector。
  4. 4入库结果进入审核或发布状态，记录版本、来源、操作者和审计日志。
网页问答流程
  1. 1前端发起提问，FastAPI 解析用户、角色、项目和可访问知识范围。
  2. 2Retrieval Service 执行权限前置过滤、关键词和向量混合检索。
  3. 3PostgreSQL 做二次权限复核，LangGraph 组织上下文、工具调用和引用来源。
  4. 4LLM 生成答案，返回引用、置信提示和可追溯记录，并写入问答日志。
阶段演进路线
MVPFastAPI + PostgreSQL + LangGraph + Celery，完成知识入库、权限问答、来源追溯。
试点加入 pgvector、rerank、Langfuse/Phoenix、日报周报和企业微信触达。
业务闭环质量安全整改、责任人、截止时间、复查、审批，必要时引入 Temporal。
平台化多 Agent 协同、跨项目经验复用，评估 AgentScope / Microsoft Agent Framework。
核心原则：Agent 不保存正式业务状态，所有业务数据、权限判断和审计留痕都回到 FastAPI 与 PostgreSQL；Hermes、AgentScope、RAGFlow 等平台只作为某一层能力接入。
