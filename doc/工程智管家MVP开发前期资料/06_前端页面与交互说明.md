# 工程智管家 MVP 前端页面与交互说明

> 文档状态：开发前期基线版
> 编制日期：2026-06-09
> 文档目的：说明 MVP 前端页面结构、信息架构、关键交互和页面验收点。

---

## 1. 前端设计原则

工程智管家面向项目一线使用，前端不应做成复杂后台系统。工地端应围绕“任务”和“风险”组织，后台配置由实施人员使用。

前端采用独立 Web 工程，不使用 Python 前端。推荐技术栈为 Vue 3 + TypeScript + Vite + Element Plus，配合 Vue Router、Pinia 和 Axios/OpenAPI Client 调用后端 FastAPI JSON 接口。Python 负责后端 API、数据库、异步任务和智能工作流，前端负责页面路由、表格表单、任务操作、审核交互、文件上传和异步作业进度展示。

设计原则：

- 工地端首页以任务为中心。
- 一线用户少看配置，多处理任务、材料和确认。
- 每个页面都要明确下一步操作。
- 智能生成内容必须可编辑、可确认、可追溯。
- 风险、逾期、缺项要突出，但不制造信息噪音。
- 耗时操作（日报解析、草稿生成、网页填报）走异步作业，页面以进度状态轮询展示，不阻塞用户操作；处于“待人工确认”（工作流暂停）的事项应引导用户完成确认后继续。
- 网页填报助手必须明确安全边界：不保存密码、不绕验证码、不自动提交。

## 2. 页面结构

建议前端工程放在仓库 `frontend/` 目录，后续 Vite 工程结构如下：

```text
frontend/
├── package.json
├── vite.config.ts
├── index.html
└── src/
    ├── api/          # 后端 API 封装与类型
    ├── router/       # 页面路由
    ├── stores/       # Pinia 状态
    ├── views/        # 页面级组件
    ├── components/   # 通用业务组件
    ├── styles/       # 全局样式与设计变量
    └── types/        # 前端类型定义
```

```text
工程智管家
├── 工地端
│   ├── 首页
│   ├── 任务中心
│   ├── 风险任务详情
│   ├── 日报解析确认
│   ├── 风险草稿审核
│   └── 填报包预览与网页填报助手
└── 后台配置
    ├── 项目配置
    ├── 成员与责任配置
    ├── WBS 计划导入
    ├── 风险源清单导入
    ├── WBS-风险源关联
    ├── 日报目录配置
    ├── 提醒规则配置
    ├── 上报模板配置
    ├── 平台字段映射
    └── 操作日志
```

## 3. 工地端首页

### 3.1 页面定位

工地端首页是一线用户进入系统后的工作台，不展示复杂后台菜单。

### 3.2 页面内容

| 区域 | 内容 |
|---|---|
| 今日待办 | 今日需要处理的任务 |
| 即将触发风险 | 未来 3/7/14 天即将触发的风险 |
| 逾期任务 | 已超过截止时间的任务 |
| 待补充材料 | 缺少照片、监测日报、审批资料等任务 |
| 待确认日报 | 需要人工确认的日报解析结果 |
| 待审核草稿 | 需要审核的风险上报草稿 |
| 待填报事项 | 已生成填报包但未完成平台草稿的事项 |
| 快捷入口 | 上传文件、查看风险、查看任务 |

### 3.3 关键交互

- 点击任务卡片进入任务详情。
- 点击风险卡片进入风险任务页面。
- 点击待确认日报进入解析确认页。
- 点击待审核草稿进入草稿审核页。
- 点击待填报事项进入填报包预览。

### 3.4 验收点

- 用户能在首页看到自己需要处理的事项。
- 逾期、风险、缺项有明确标识。
- 首页不暴露复杂配置项。

## 4. 任务中心

### 4.1 页面定位

任务中心是工地端主入口，所有提醒、确认、补充和填报事项都应进入任务中心。

### 4.2 列表筛选

| 筛选 | 说明 |
|---|---|
| 我的今日任务 | 当前用户今日需要处理 |
| 我的逾期任务 | 当前用户已逾期任务 |
| 我负责的风险源 | 当前用户承担责任的风险 |
| 我负责的任务 | 当前用户负责处理或确认的任务 |
| 待补充材料 | 缺少材料的任务 |
| 待确认日报 | 日报解析待确认任务 |
| 待审核草稿 | 风险草稿待审核任务 |
| 待填报平台事项 | 填报包待处理任务 |

### 4.3 任务列表字段

- 任务标题。
- 任务类型。
- 风险等级。
- 关联项目。
- 关联 WBS。
- 关联风险源。
- 负责人。
- 确认人。
- 截止时间。
- 当前状态。
- 缺项数量。

### 4.4 任务详情

任务详情应展示：

- 任务基本信息。
- 触发原因。
- 关联 WBS 和风险源。
- 所需材料。
- 已提交材料。
- 操作日志。
- 处理结果。

操作按钮：

- 开始处理。
- 补充材料。
- 提交确认。
- 退回补充。
- 确认完成。
- 取消任务。

## 5. 风险任务页面

### 5.1 页面内容

- 风险名称。
- 风险等级。
- 风险类型。
- 关联 WBS 工序。
- 计划开始时间。
- 当前风险状态。
- 触发规则。
- 所需材料。
- 已提交材料。
- 缺少材料。
- 责任人。
- 确认人。
- 相关日报。
- 相关附件。

### 5.2 主要操作

- 查看触发原因。
- 补充风险材料。
- 确认风险状态。
- 生成风险进展草稿。
- 查看历史草稿。
- 进入填报包。

## 6. 日报解析确认页

### 6.1 页面内容

- 来源文件。
- 文件类型。
- 日报日期。
- 施工内容。
- 当前进度。
- 累计进展。
- 存在问题。
- 明日计划。
- 风险相关内容。
- 监测相关内容。
- 现场照片。
- 匹配的 WBS 工序。
- 解析置信度。

### 6.2 主要操作

- 修改日报日期。
- 修改施工内容。
- 调整匹配 WBS。
- 标记照片和附件。
- 确认解析结果。
- 退回重新解析。

### 6.3 验收点

- 用户能看懂系统解析结果。
- 用户能修改错误字段。
- 确认后的内容能被草稿生成引用。

## 7. 风险草稿审核页

### 7.1 页面内容

- 草稿标题。
- 草稿正文。
- 字段化信息。
- 风险源信息。
- 关联 WBS 信息。
- 日报进展引用。
- 附件清单。
- 缺项提示。
- 数据来源。
- 审核记录。

### 7.2 主要操作

- 编辑草稿正文。
- 调整字段内容。
- 添加人工说明。
- 补充附件。
- 发起材料补充任务。
- 提交审核。
- 审核确认。
- 生成平台填报包。

### 7.3 验收点

- 草稿可编辑。
- 缺项明确可见。
- 来源可追溯。
- 未确认草稿不能生成正式填报包。

## 8. 网页填报助手页面

### 8.1 页面内容

- 目标平台。
- 业务流程名称。
- 待填字段。
- 待上传附件。
- 字段映射状态。
- 登录提示。
- 自动录入进度。
- 失败字段提示。
- 草稿保存状态。
- 提交前人工确认提示。

### 8.2 主要操作

- 预览填报包。
- 打开目标平台。
- 确认已登录。
- 启动自动录入。
- 查看录入进度。
- 查看失败原因。
- 标记平台草稿已保存。
- 标记用户已提交。

备注：启动自动录入后，填报助手作为异步作业运行，页面轮询作业状态展示“录入中 / 已完成 / 字段失败”，始终停在最终提交前。

### 8.3 安全提示文案

页面必须明确展示：

```text
账号、密码和验证码请只在目标平台页面输入。系统不会保存密码，不会绕过验证码，不会自动最终提交。
```

## 9. 后台配置页面

### 9.1 项目配置

字段：项目名称、标段名称、所属单位、项目状态、说明。

### 9.2 成员与责任配置

字段：成员、联系方式、责任标签、责任范围。

### 9.3 WBS 导入

功能：上传文件、预览解析结果、人工调整、确认导入。

### 9.4 风险源导入

功能：上传文件、预览解析结果、人工补充控制要求和材料要求、确认导入。

### 9.5 WBS-风险关联

功能：选择 WBS、选择风险源、配置触发阶段、提醒天数、责任人、确认人、关联依据。

### 9.6 日报目录配置

字段：incoming、processing、processed、failed、archive 目录路径，扫描频率，启用状态。

### 9.7 提醒规则配置

字段：风险等级、提前提醒天数、提醒频率、默认负责人、默认确认人。

### 9.8 模板与字段映射

功能：上报模板维护、平台字段映射、附件类型映射。
