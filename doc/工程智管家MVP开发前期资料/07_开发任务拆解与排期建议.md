# 工程智管家 MVP 开发任务拆解与排期建议

> 文档状态：开发前期基线版
> 编制日期：2026-06-09
> 文档目的：将 MVP 需求拆解为可排期、可分工、可验收的开发任务。

---

## 1. 拆解原则

- 先做主闭环，再做增强功能。
- 先做后台底图和任务中心，再做网页填报助手。
- 每个里程碑都要有可演示成果。
- 每个任务都要对应需求、接口、数据库和页面。
- 日报解析、草稿生成、网页填报先做可人工确认的版本，不追求完全自动化。

---

## 2. 里程碑总览

| 里程碑 | 目标 | 主要成果 |
|---|---|---|
| M0 开发准备 | 样例、字段、规则、环境确认 | 样例文件、字段字典、模板、任务看板 |
| M1 基础底座 | 项目、成员、责任、日志 | 后台基础配置可用 |
| M2 WBS 风险底图 | WBS、风险源、人工关联 | 可生成风险预警依据 |
| M3 任务中心 | 风险提醒任务到人 | 工地端任务闭环可用 |
| M4 日报解析 | 目录扫描、文件解析、人工确认 | 实际进展可复用 |
| M5 草稿生成 | 缺项检查、风险草稿、审核确认 | 风险上报草稿可用 |
| M6 填报助手原型 | 填报包、字段映射、辅助录入 | 平台草稿可保存 |

---

## 3. M0 开发准备

### 3.1 业务准备

| 任务 | 负责人 | 输出 |
|---|---|---|
| 收集 WBS 进度计划样例 | 业务方/实施 | 真实 WBS 文件 |
| 收集风险源清单样例 | 业务方/实施 | 真实风险源文件 |
| 收集日报文件样例 | 业务方/实施 | Word/Excel/PPT/PDF/图片样例 |
| 确认风险上报模板 | 业务方/产品 | 模板字段清单 |
| 确认目标平台字段 | 业务方/实施 | 平台字段表 |
| 确认项目成员和责任 | 项目部/产品 | 成员责任清单 |

### 3.2 技术准备

| 任务 | 输出 |
|---|---|
| 确认数据模型与主键策略 | 数据模型清单 + 主键统一 bigint 方案 |
| 确认数据库迁移方式 | 建表与迁移方案 |
| 确认对象存储（MinIO）与附件归一表 | 存储与附件字段方案 |
| 确认前端工程基线：Vue 3 + TypeScript + Vite + Element Plus | 前后端分离、路由、状态管理、接口封装与 UI 组件方案 |
| 确认异步与调度：Celery（Beat + Worker）+ Redis | 扫描/提醒定时与耗时作业队列方案 |
| 确认 LLM 供应商与统一客户端 | 模型/超时/重试/降级与结构化输出 schema 方案 |
| 确认 LangGraph + PostgreSQL Checkpointer | 工作流节点图与人在环 interrupt 方案 |
| 确认 Hermes 复杂子任务工具边界 | 未知格式兜底、跨系统取数、复杂网页操作的调用边界与部署约束 |
| 确认自然语言录入预留范围 | 本期只占位的数据模型、接口和页面入口边界 |
| 确认文件解析库（docx/xlsx/pptx/pdf/图片） | 按 MIME 分发的 Parser 接口方案 |
| 确认网页填报助手技术路线（Playwright） | 受控自动化边界与进程模型方案 |

## 4. M1 基础底座任务

### 4.1 后端

- 扩展项目基础信息。
- 完善项目表和项目成员接口。
- 增加责任标签表。
- 增加成员责任绑定。
- 增加操作日志表。
- 增加配置类 API。
- 搭建异步基础设施骨架：Celery Beat 定时调度 + Celery Worker 队列 + Redis + async_jobs 表，供后续扫描/提醒/解析/工作流复用。

### 4.2 前端

- 项目配置页。
- 搭建 `frontend/` 独立前端工程骨架，接入路由、状态管理、API 封装和基础布局。
- 项目基础信息配置入口。
- 成员与责任配置页。
- 操作日志基础查询页。

### 4.3 完成判断

- 能创建 FXZ1.2 标项目。
- 能配置成员和多个责任标签。
- 能按项目查看操作日志。

## 7. M4 日报解析任务

### 7.1 后端

- 增加日报目录配置。
- 增加日报文件表。
- 增加文件指纹和去重逻辑。
- 增加目录扫描定时任务（Celery Beat）。
- 搭建统一 LLM 客户端与结构化输出 schema。
- 实现按 MIME 分发的 Parser 接口（Word、Excel、PPT、PDF、图片）。
- 用 LangGraph 实现日报解析工作流：解析→抽取→WBS 匹配→低置信度 interrupt 人工确认→回流，检查点落 Postgres。
- 解析作业由 Celery Worker 执行，状态写 async_jobs。
- 增加日报解析结果表。
- 增加进度条目和 WBS 匹配逻辑。
- 增加人工确认接口（从检查点恢复工作流）。

### 7.2 前端

- 日报文件列表。
- 日报解析详情页。
- 解析结果编辑。
- WBS 匹配调整。
- 确认按钮和失败提示。

### 7.3 完成判断

- 能扫描指定目录。
- 能避免重复处理文件。
- 能提取日期、进度、照片、问题。
- 能人工确认日报解析结果。

## 8. M5 草稿生成任务

### 8.1 后端

- 增加风险草稿表。
- 增加材料缺项检查服务。
- 用 LangGraph 实现草稿生成工作流：多源聚合→套模板生成→缺项检查→interrupt 人工审核打回重生成循环。
- 增加草稿编辑、审核、确认接口。
- 增加填报包表。
- 增加填报包生成接口。

### 8.2 前端

- 风险草稿审核页。
- 缺项提示组件。
- 附件清单组件。
- 数据来源展示。
- 填报包预览页。

### 8.3 完成判断

- 能为指定风险源生成草稿。
- 草稿能标明缺项和来源。
- 草稿能人工修改和确认。
- 确认后能生成填报包。

## 9. M6 填报助手原型任务

### 9.1 后端

- 增加平台字段映射表。
- 基于 Playwright 实现受控填报助手服务（用户自登录、不存密码、不绕验证码、不自动提交）。
- 增加填报包预览接口。
- 增加填报助手启动和进度接口。
- 增加失败字段记录。
- 增加保存草稿状态记录。

### 9.2 前端/自动化

- 填报助手页面。
- 待填字段预览。
- 用户登录提示。
- 自动录入进度。
- 失败字段提示。
- 提交前暂停提示。

### 9.3 完成判断

- 用户自行登录平台。
- 系统不保存密码。
- 系统辅助录入字段和上传附件。
- 系统保存草稿并停留在最终提交前。

## 10. 推荐开发顺序

第一轮建议顺序：

```text
项目/成员/责任/日志
  -> WBS 导入
  -> 风险源导入
  -> WBS-风险关联
  -> 风险提醒任务
  -> 任务中心
  -> 日报目录扫描
  -> 日报基础解析
  -> 日报人工确认
  -> 风险草稿生成
  -> 填报包预览
  -> 网页填报助手原型
```

不建议一开始就投入大量精力做网页填报助手，因为它依赖草稿、字段映射、附件和人工确认都先稳定。
