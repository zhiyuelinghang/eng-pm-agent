# 知识库问答接入平台资料助手

知识库问答页面由「平台设置 → 资料助手」指定的智能体负责理解和回答问题。普通问候、称呼偏好和上下文已足够的追问不强制查询知识库；需要资料依据时，助手调用已有的项目知识库工具。项目概况、任务等信息使用管理端已分配给该助手的数据库交互工具。

## 会话与管理配置

- 管理端「平台设置」增加第四个职责「资料助手」。管理员选择已启用、配置固定模型并开启「启用项目资料查询」的智能体，保存或取消分配；不能与总控、初始化或任务助手共用同一个智能体。
- 资料问答不再显示助手选择器，只使用平台指定的职责。指定助手隐藏于普通业务目录，前端统一显示「资料助手」。新对话由服务端解析当前分配；客户端不能指定其他业务智能体替代。切换或取消职责后，旧记录保留查看，后续发送要求新建对话或恢复配置。
- 职责保存在现有平台设置 JSON 的 `knowledge_assistant_agent_id` 中，默认空值兼容旧配置；本次新增职责不涉及数据库结构变更或自动迁移，也不会扩大所选智能体的记忆权限。
- 页面复用 AgentConversation 和现有流式发送、确认、停止、历史接口。工程知识库会话只保留资料范围和原有历史，并通过唯一外键关联平台会话。
- 身份、项目归属、记忆读写与学习策略沿用平台会话和智能体配置。开启知识库能力不会自动扩大数据库工具或记忆权限。
- 这些会话不参与普通业务工具页面的“最近会话”选择，避免两个入口相互替换。
- 原有 WeKnora 问答记录保留展示，不删除、不改写成平台智能体历史。接入后的上下文由平台会话持续保存；旧问答不是新助手已执行过的工具证据。

## 范围与调用

页面不再预先创建 WeKnora 会话或展开整个文件夹才能发送问候。平台会话在资料工具实际调用时，向后端请求最新授权。

后端使用持久化资料范围与当前用户可读文件的交集；多选项取并集，目录按完整路径边界匹配。权限减少、目录删除或范围无可读资料时，空范围不能回退为全项目或远端全库。查询后再次校验权限，复用已有工具的撤权保护。

助手收到平台身份与入口职责提示，不能将称呼偏好当作账号权限变更；不能冒充 WeKnora；必须区分资料依据、实时业务数据和一般解释。

## 用户体验

- 立即展示发送的消息与连接状态；收到事件后展示真实思考和工作记录，不暴露工具内部名称、参数或原始结果。
- 显示本次处理时间，20 秒未收到新事件时提示可以等待或停止，不伪造进度。
- 正文流式显示，成功资料工具返回的引用展示为可定位、下载的来源卡片。
- 沿用平台工具的业务确认卡片，不绕过写操作权限或确认。
- 用户上翻时停止自动滚动，提供返回最新进度按钮。
- 停止仍接收服务端最终记录；连接意外结束不自动重发，提供恢复历史记录入口，避免重复业务操作。
- 切换项目、卸载页面时中止旧请求，迟到结果不覆盖新项目视图。
- 知识库目录准备异常不会阻塞资料助手的普通对话；实际资料查询仍受就绪状态约束。
