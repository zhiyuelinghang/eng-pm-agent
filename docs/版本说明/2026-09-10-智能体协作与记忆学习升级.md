# 2026-09-10 智能体协作与记忆学习升级

本记录说明该版本的功能变化和升级事项。现行操作规则见[项目入口](../../README.md)，
具体环境的模型绑定、数据库修订和安装包需要分别核对。

主体功能提交：[f0dd2021](https://github.com/zhiyuelinghang/eng-pm-agent/commit/f0dd2021df22925e7cd13b39cd4c4087e71161b5)，比较基线：`c726928a`。

## 功能变化

- 固定总控、项目初始化、知识库助手和任务助手四个职责，明确各自业务入口。
- 协作区分总控调用许可、其他智能体邀请许可与调用方明确名单；移除旧层级配置。
- 业务智能体区分公开/内部、启用和发布；管理界面集中配置能力，保留独立调试。
- 任务助手通过任务引擎生成可编辑私有草稿，正式发布仍需用户确认；日历字段转换保留周期规则。
- 记忆访问根据真实入口、用户、项目、来源和调用链自动确定，取消逐智能体记忆配置。
- 长期记忆、后台学习、索引与对话压缩分工明确；全局记忆配置收敛为六项。
- 协作候选、群聊受众、来源撤销和本次不记忆/不学习要求沿调用链持续校验。
- 模型默认参数集中保存，协作读取当前有效模型；共享文本接口替代旧平台独立模型配置。
- 支持模型能力范围内的原生图片输入；未知输出能力不再被自动写成 8192。
- 权限审核移入独立配置页；统一长任务运行、重复失败保护、截断处理和阶段保存。

## 数据库升级

该版本涉及以下业务数据库修订，目标修订为 `fd73b916a204`：

| 修订 | 作用 |
| --- | --- |
| `fa39c501a842` | 业务学习来源与运行受众绑定。 |
| `fc62e708b193` | 统一记忆运行、节点、证据及候选记录，调整学习来源和历史审计。 |
| `fd73b916a204` | 真实任务生成关系及确认事件的学习排除。 |

缺少完整来源证据的历史成果按迁移规则停止作为有效成果使用，保留原文和审计。
相关修订不提供自动删除证据的降级路径。迁移定义见[业务数据库修订](../../backend/alembic/versions)。

升级前停止服务并备份 PostgreSQL、配置和运行文件。随发布单独交付并审阅对应 SQL；
不能假定代码更新包已经包含 SQL。应用启动不自动迁移，完整步骤见[服务器部署说明](../../服务器部署说明.md)。

## 显式配置转换

以下工具默认预览，实际修改须显式应用。按来源版本选择工具，不直接照搬其他环境的模型或凭证 ID。

| 工具 | 用途 |
| --- | --- |
| [清理逐智能体记忆策略](../../scripts/remove_agent_memory_policy.py) | 清理中间阶段字段。 |
| [精简全局记忆配置](../../scripts/simplify_memory_settings.py) | 转换六项公开配置并更新版本。 |
| [精简权限审核配置](../../scripts/simplify_permission_reviewer.py) | 清理旧启用和备用模型字段，检查旧停用配置的激活风险。 |
| [清理假定输出上限](../../scripts/remove_assumed_model_output_limits.py) | 清理旧动态模型被假定的 8192 能力。 |
| [统一聊天模型绑定](../../scripts/align_platform_chat_model.py) | 仅用于已明确核验的目标模型场景。 |

这些单项工具不能覆盖所有历史版本。较早数据库需先盘点旧字段并审阅对应转换。
启动程序不隐式转换旧职责、层级或配置。

后台学习的暂停和成果提交依赖同一 PostgreSQL 事务边界，平台配置与记忆存储须满足
同库要求；Redis 配置存储或跨数据库部署不提供隐式降级。WeKnora 的问答模型由外部服务
独立管理，平台模型调整不代表外部服务同步修改。

部署还需构建两套前端、更新任务引擎运行包并重启对应服务。Git 更新不携带真实配置、
数据库和已安装运行包，也不表示目标服务器已完成上述步骤。
