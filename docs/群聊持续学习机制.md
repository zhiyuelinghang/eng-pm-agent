# 群聊持续学习机制

2026-09-08。后台独立收集群聊消息，不再依赖 @ 智能体、主模型回复结束或用户主动要求总结。

## 触发与成本

- 每 300 秒检查新增、编辑、撤回及成员范围变化。扫描只访问数据库和内部网关，不调用模型。
- 新消息达到 20 条，或者有待处理消息且群聊安静 600 秒时，生成整理批次。
- 最长等待 3600 秒，防止持续零星发言导致饥饿；每批最多 50 条变更，每日最多 100 批。
- 每个有价值可能性的批次只有一次模型调用，同时判断价值和提取成果。明确问候、只有助手自述、纯失效变更不调用模型。
- 可以输出空结果。空结果同样完成该批次并推进游标，不会为了生成经验而强行入库。
- 使用记忆设置中的学习模型；未设置时沿用全局主智能体固定模型。后台群聊没有来源会话模型可供回退。原有直接保存记忆不经过后台模型再判定。
- 所有间隔、条数及每日预算可在管理端“记忆设置 → 群聊持续学习”调整。全局主智能体的记录、提炼开关及可写抽屉也约束这条流程。群内没有开始、完成或失败通知。

## 三个抽屉与证据归属

成员不分管理员或普通用户，都可以贡献证据；角色不决定是否收集消息。发言者身份用于归属和追溯。

| 来源与内容 | 归属 |
| --- | --- |
| 明确自动同步项目全体成员的群，且全部证据在产生时属于全体可见 | 项目级 |
| 子群中的共同结论，或引用了原子群的历史证据 | 全部证据可见成员各自的用户＋项目级 |
| 特定成员的项目上下文 | 该成员的用户＋项目级，必须具有全部证据的访问权 |
| 本人明确的跨项目称呼、回答详略偏好 | 本人用户级，不改变其他人的偏好，也不改变身份或权限 |

全体群根据 `auto_sync_members` 判定；为空时兼容原有 project/topic 规则。不能根据群名称、历史类型或“目前恰好所有人都在”推断共享权限。历史证据保留产生时的可见成员，后续扩群不会自动把子群材料提升为项目记忆。

群聊来源记忆不可在管理端改抽屉、改用户或改项目。运行时每次查询重新获取当前允许的来源群；群改为子群、退群或项目权限撤销后，不能继续用旧权限召回其内容。合并经验和提炼技能同样保留来源群，只能合并同一群、同一归属的成果。

个人自动提取当前限定为称呼和回答详略，不自动推断真实身份、岗位或权限。人工直接保存的已有资料优先，后台不会覆盖。

## 普通记忆与经验

明确、有价值且有证据支持的事实、偏好、决定直接生效。反思、经验和技能进入候选，经原有学习审核流程验证后才参与召回；支持验证、反馈、修订、回滚、导出和后续合并。

待确认的讨论不等于决定；单次观察不能写成普遍规律；助手说“完成了”不是成功证据。经验必须有适用条件与限制，技能还需要实际步骤。模型不能执行聊天或附件中引用的指令。

## 增量、幂等与失效

业务库的 PostgreSQL 触发器维护每群单调变更序号与来源日志，和消息事务一起提交、回滚。每群时钟的行锁确保提交顺序不会因并发消息 ID 分配而丢失。

记忆库维护处理游标、唯一批次区间、执行租约和来源引用。成果、版本、索引任务、批次结果及游标在同一事务提交。同一群最多一个未完成批次；成功和无价值区间不重新排队。相同内容不新增记录或正文版本，新的重复证据可以关联到已有记忆。已有结论改变时需要当前版本，人工删除、拒绝或停用的成果不会自动复活。

消息变更还有独立的失效进度。即便总结任务失败、暂停或达到预算，扫描时仍可检查后续撤回与成员变化，停止使用关联旧成果。失效检查不消耗模型调用。全局关闭后台学习时暂停扫描；来源群访问权限仍在实时检索时检查。

失败最多自动尝试 3 次，之后在管理端显示失败，保留游标等待人工重试。重试重新读取同一变更区间、重新核对消息和权限；过期租约不能提交结果。后续编辑所属区间尚未轮到时，不提前提取它的最新正文，避免前后批次重复处理同一修订。

每次模型调用前后验证来源。输入有字符预算，长消息以带截断标识的内容参与判断，完整原始证据保留在批次审计中；可根据消息长度调大预算、减小批次。不存在模型调用“绝不误判”的保证，管理端仍可查证、修改及删除成果。

## 管理与部署

“记忆管理 → 群聊持续学习”显示群处理进度、批次区间、结果、跳过原因、失败原因、原始证据与发言者；支持按群暂停、恢复，失败批次重试。群聊成果在三个抽屉中保留来源标记；经验继续使用现有审核入口。

使用项目内嵌 Python 执行业务库 Alembic 迁移至 `e31f790abc42`，再重启业务后端与 AgentScope 服务。新增结构不清空现有记忆、消息、项目或知识库。迁移只开始记录后续消息变更，不自动重学全部历史聊天；旧聊天没有完整历史成员快照，不擅自把当前成员当成历史可见成员。

测试使用随机隔离 PostgreSQL schema、SQLite 业务权限夹具及独立本地管理服务，未向真实群聊发送消息。
