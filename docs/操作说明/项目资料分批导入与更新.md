# 项目资料分批导入与更新

「工程配置 → Dobby 配置助手」支持初次建档和已有项目的资料补充。每次只提供当前要处理的资料即可，不要求人员、WBS、风险和质量指标一次齐全。

## 核对与提交

1. 输入说明或添加附件。助手读取项目现有资料，按涉及的分区生成草稿。
2. 点击草稿上的「核对草稿」。即使其他分区还在整理，已生成的记录也可进入差异窗口。
3. 各资料分区默认展开，主要信息直接以表格展示。可整组选取或逐条调整本次提交内容，也可按关键词、变更状态筛选；顶部分区按钮用于跳转，不会隐藏其他分区。工程基本信息可以逐字段选择。
4. 工程信息的更新按「现有数据」与「本次资料」逐行对比，其他分区在变化字段处直接显示新旧值；新增资料直接显示本次内容。匹配不确定时，在对应记录下选择旧记录，或明确作为新增。
5. 等待所选内容核验通过。有提醒时先逐项核对；新增人员需要确认账号与初始密码。点击确认后只保存所选内容，剩余草稿可稍后继续。

新增、更新、无变化、待匹配和已提交分别展示。改变选择或匹配结果后会重新核验，旧预览不能继续提交。项目数据或草稿在核对期间发生变化时，需要刷新差异后重新确认。

WBS 按父子层级查看，可逐节点或全部展开、收起，分区和层级折叠均不改变已选内容。搜索子节点时
保留上级路径，仅作为路径显示的祖先不会被筛选结果的全选操作选中。已有人员显示沿用的登录账号；字段使用中文
名称，未变化的空占位字段不显示，日期仍保留有意义的时间和时区差异。

对话中的执行计划显示每项待办、完成进度、负责人及前置任务；已结束的会话不会让
未完成任务继续转圈。协同成员保留团队、分配任务、状态、耗时及可展开的工作记录，
成员反馈保留来源。多人团队另有可折叠概览，具体邀请与工作记录仍按原时间位置显示。

连接中断后可点击错误提示旁的「重新同步会话」，读取已保存的正文、计划与协同记录。
同步不会重发请求；同步期间可以编辑输入，但暂不能发送，避免旧历史覆盖新一轮消息。
指定会话已不可用时会提示选择其他会话，不会静默切到另一段历史。

成员任务结算及团队清理前，运行端会把真实进度归档到原分配消息，并绑定对应的任务版本。
历史读取不依赖平台完整接收实时事件；已删除且没有归档的旧工作明细无法追补。

## 数据保留与关联

- 本次没有提供的分区、记录和字段保留原值；空白或未识别字段不会自动删除、清空原数据。本入口不推断删除操作。
- 更新保留正式记录 ID、任务与资料关联、负责人、执行状态等未涉及字段，已有任务的项目可以继续导入。
- 人员复用身份证对应的现有账号，不重设密码。新增岗位时沿用已有账号姓名；资料姓名不一致会提示核对。
- WBS 按项目内编码匹配，人员按身份证与岗位匹配，质量指标按 WBS 匹配。风险序号可能随资料重排，不能单凭序号覆盖旧风险。
- 校验以现有项目数据和本次选择合并后的结果为准。单独提交质量指标时可关联已存在的 WBS；缺少父级、前置工序或关联 WBS 时，先补充对应记录或一并选择提交。
- 被父子关系、前置关系或质量指标引用的 WBS 编码，暂不支持在导入过程中直接重命名；普通名称、日期、进度等字段可更新。
