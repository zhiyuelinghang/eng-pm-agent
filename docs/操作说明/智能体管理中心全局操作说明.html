智能体管理中心操作手册

用于平台管理员配置模型、智能体及业务能力。管理中心负责配置和调试，工程管理平台承载真实用户、项目和业务操作。

本文提供操作路径。详细规则分别见分工与协作、记忆与学习、自动运行管理和模型与图片输入。

首次配置

  1. 进入「模型与连接」，添加凭证，建立模型目录，保存凭证与模型参数后测试连接。
  2. 在「平台主智能体」选择固定职责直接配置；新增专业能力时，进入「业务智能体」。
  3. 填写名称、工作指令和模型策略，按需要设置业务可见性、执行权限与协作接收许可。
  4. 在能力页签分配所需的技能、MCP、数据库交互和协作对象，分别保存分配。
  5. 打开「调试」，验证已保存配置；需要业务端直接使用的公开业务智能体，再启用并发布。

编辑或勾选不会自动生效。切换对象、能力页签或离开页面前，处理未保存草稿；读取失败时先重试，不把空列表视为已经取消分配。

主智能体与业务智能体

「平台主智能体」和「业务智能体」是两个独立入口。四个主智能体职责固定、始终启用，不能停用、删除或替换职责对象；未配置时直接填写该职责的模型和工作指令。

固定职责
职责业务入口与工作配置重点
Dobby 总控首页理解需求、组织协作、汇总答复模型、必要业务能力；协作名单按目标许可自动形成
项目初始化初始化页面组织资料、草稿和核验编排技能、草稿交互、专家名单和核验版本

业务智能体可新增，使用范围分为「公开」和「内部」。「允许平台运行」控制能否使用及协作；「发布到平台」只控制公开入口。公开、已启用且已发布的业务智能体才进入业务目录和普通 @ 候选；内部智能体用于授权协作，不发布。

在对象页点击「编辑智能体」维护基本信息、模型、平台接入或高级设置以及协作设置。工作指令说明目标、输入和输出；权限、模型参数及协作名单使用各自配置入口。

完整边界见智能体分工与协作规则。

凭证、模型与权限审核

  1. 在「模型与连接」添加与服务兼容的凭证类型，填写名称、API Key 和服务地址并保存。密钥只保存在凭证配置中。
  2. 自动获取模型目录；服务不支持发现时手动添加，填写用途、模型 ID 和显示名称。
  3. 按模型支持情况设置思考模式、思考强度或接口扩展，保存更改。
  4. 使用「测试」检查已保存模型。修改参数后重新保存再测试；未保存草稿不会进入请求。
  5. 回到智能体编辑页选择继承或固定模型策略。固定策略需要可用凭证和模型；目标自身的固定策略优先于协作继承。

先保存，再测试。连接成功只证明本次模型请求可用，不表示工具分配、项目授权或完整业务流程已经验证。

模型参数由目录统一管理，不在每个智能体或会话重复覆盖。图片能力以模型目录登记为准；使用原图的范围和大小限制见统一模型与原生图片输入。

配置 Auto 权限审核

进入独立的「权限审核配置」，保存审核凭证、模型、最低置信度、最高自动放行风险和超时，使用页面模型测试与审核记录排查。审核员是系统服务，不是第五个主智能体，没有聊天、发布或邀请入口。

Auto 模式按需调用独立审核模型；未配置、不可用或判断不满足规则时转人工确认。明确拒绝和必须人工确认的业务操作继续生效。调试的执行权限跟随所属智能体配置，详见智能体运行自动管理。

协作授权

先配置被调用方是否接受，再配置调用方可以找谁。两端保存各自的设置，单有一份名单不构成完整授权。

  1. 打开被调用方「编辑智能体 → 协作设置」，分别设置「允许总控调用」「允许其他智能体邀请」，并说明适合承接的任务。
  2. 总控自动纳入已启用且允许总控调用的业务智能体，并固定可调用任务助手和知识库助手。
  3. 其他调用方进入「协同智能体」页签，从已启用且允许其他邀请的候选中勾选目标，保存明确名单；未选择时独立工作。
  4. 验证实际派发与结果返回。关闭接收许可后，旧名单或团队成员身份不能继续授权调用。

总控和项目初始化不接受智能体调用；不允许邀请本次运行的上级形成循环。被调用方使用自己的工具与权限，协作不把这些权限转授给调用者；用户、项目、来源及输出受众限制沿整条调用链保留。

许可组合与固定职责例外见分工与协作规则。

能力配置

选择智能体后，通过页面页签配置协同智能体、技能、MCP 和数据库交互。资源「查看详情」与勾选分配是不同操作；新增资源进入目录后仍需分配。

能力操作注意事项
技能添加或选择技能，查看内容与版本，按权限编辑、下载或移除技能提供工作方法；实际工具与数据权限仍须单独分配
MCP上传完整运行包，检查工具目录，勾选并保存分配上传检测成功不等于已分配；被使用的包先取消分配再删除
数据库交互查看表白名单，创建或选择交互，保存分配只开放所需表、字段、操作和会话范围
协同智能体保存向外调用名单目标接收许可仍需满足，详见上一节
系统工具从左侧「系统工具」搜索并查看详情目录只读，无分配开关；实际可用范围由职责、环境与权限决定

MCP 上传接受依赖完整、适配目标操作系统的 STDIO 运行包，语言不限。包必须包含平台安装清单、启动入口、自带运行时及依赖；上传时不安装依赖、不编译源码，也不借用服务器全局运行时。

打包、升级与受控平台能力见MCP 包上传与运行说明。

数据库交互：配置、绑定与关联表

数据库交互是平台表白名单之上的结构化数据能力，不是 SQL 编辑器。白名单决定可开放的表、字段、操作和数据范围；交互进一步收窄能力，智能体分配决定谁能调用，运行时再核对真实用户、项目和会话。

创建一项查询交互

  1. 选择目标智能体，进入「数据库交互」，点击「查看表白名单」。核对允许操作、可读／可写／可筛选字段、数据范围及最低角色；此处不能修改白名单治理规则。
  2. 点击「新增交互」，填写中文动作名称、用途说明和技术标识。技术标识以字母开头，仅使用小写字母、数字和下划线，创建后不修改。
  3. 选择主表白名单与允许操作，检查界面显示的执行来源和数据范围；字段选择只保留任务需要的内容。
  4. 选择「智能体直接调用」或「MCP／工作流内部调用」，并选择允许的会话类型。两种调用方式不能在同一交互中同时生效。
  5. 按需要配置可信上下文绑定与关联表，检查自动生成的调用参数，无需手写 JSON Schema。
  6. 保存交互并开启「允许分配和调用」；在目录勾选该交互，另行点击「保存分配」。
  7. 验证正确能力被调用、字段符合预期。涉及真实项目数据时，从获授权的工程业务入口验证项目隔离，管理端调试不能替代业务身份验证。

可信上下文绑定

绑定方式用途
限定记录范围查询或写入只能命中当前项目、用户、会话或执行智能体对应的记录
写入时自动填充写操作由平台填入可信值，调用方不能伪造

身份与项目从真实会话解析，不让模型自由填写。白名单已按当前项目隔离时，无需重复添加无关绑定；需要进一步按会话或执行智能体隔离时再配置对应字段。

关联表规则

  • 只能选择已加入白名单、与当前查询路径存在真实数据库外键的表；字段同名不能代替外键，不允许任意手写连接条件。
  • 关联别名不能重复，也不能使用保留的 main；分别选择需要的返回字段与筛选字段。
  • 「保留主表全部记录」在关联对象缺失时仍返回主表记录；「只保留匹配记录」会过滤未匹配记录。
  • 多表关联只用于查询；新增、修改和删除只作用于主表，多表写入须另行设计受控业务流程。

例如查询任务负责人时，用主表的负责人外键关联账号表，只返回姓名等必要字段。查询按参数中的分页上限处理；修改前先读取当前记录，支持的预期值条件用于避免覆盖并发修改。

写操作与权限

确认主表允许相应新增、修改或删除，只开放该动作必需字段，并设置所需可信绑定。智能体直接调用的写操作固定经过权限审核；只读敏感查询可额外要求确认。运行时仍检查会话写权限、用户角色、项目归属、外键引用和并发条件，配置页无法绕过这些检查。

与 MCP 配合

常规方式是把只读交互与 MCP 分配给同一智能体，由智能体先查询再分析；需要写回时使用独立写交互。大量分页或封装流程可选择「MCP／工作流内部调用」，交互不会直接暴露给模型，但必须分配给实际执行 MCP 的智能体。

采用平台数据库交互的 MCP 须声明受控能力并使用平台注入的网关和真实会话身份，不在包内填写账号、令牌、连接字符串或原始 SQL。任务引擎专用存储有独立约束，不能当作普通业务包的通用权限；协议和例外见MCP 包说明。

项目初始化：技能分工与核验版本

平台先解析附件，初始化智能体组织计划和专项草稿，核验 MCP 检查平台组装的数据，用户核对后才正式入库。核验包只承担核验，不代替编排、资料理解或人工确认。

给初始化智能体分配编排技能、职责内数据库交互和获授权专家名单；给专家分配对应技能、必要只读交互及自己的分区写交互。只有实际涉及的专家参与本次运行，专家不写其他分区或正式业务表。

正常运行顺序

  1. 上传附件，平台反馈接收与解析状态，并保存文件和分块来源。
  2. 解析预处理后，初始化智能体先创建执行计划，再读取必要分块、识别分区并建立或继续草稿。
  3. 邀请相关专家时传递草稿、文件和分块标识；专家分页读取来源，完成各自分区，不复制整份附件进邀请文本。
  4. 初始化智能体确认所需分区已保存，只提交草稿标识。平台组装规范化数据，运行当前选定的核验 MCP，并保存定位到记录和字段的问题。
  5. 用户在工程平台核对草稿、问题和建议，修正并确认后由平台原子写入正式数据。发现问题与核验通过必须分别显示。

初始化过程只读项目记忆，不把草稿交互写成正式长期事实。详细运行约束见记忆与学习规则；编排步骤由初始化编排技能维护。

上传、切换和删除核验版本

  1. 进入「平台主智能体 → 项目初始化 → 初始化核验」，上传版本号递增、运行时和依赖完整的核验包。
  2. 上传不会自动切换；在「使用版本」中选择目标，再点击「保存初始化配置」。之后新触发的核验使用该版本。
  3. 需要修改规则时，下载所选版本作为基线，修改、提升版本并重新打包上传。
  4. 删除历史版本前确认它未被使用；当前使用版本须先切换并保存其他版本，才能删除。历史核验结果不会因切换版本自动重跑。

核验 MCP 不出现在普通智能体的可分配 MCP 目录，只在「初始化核验」管理。平台负责读取草稿和保存结果，核验包不直接连接业务数据库。

安装包要求见MCP 包说明，附件解析机制见附件解析工具说明。

记忆与学习

「记忆配置」集中维护六项：后台学习总开关、独立学习模型、业务交互来源、已确认业务事件来源、群聊消息来源，以及对话压缩模型。开启学习须选择可用模型和至少一种来源；压缩模型留空表示使用当前对话模型。

修改后点击「保存更改」；「放弃更改」只恢复上次保存值。发生配置版本冲突时保留草稿，处理差异后再保存，没有「恢复默认」入口。

「记忆管理」提供记忆库、学习记录和运行诊断。可搜索、查看正文、来源及历史，删除不需要的记忆；不提供人工编辑、审核、合并、回滚或手动任务重试。

记忆分为用户、用户＋项目、项目三个范围，由系统按职责、真实来源和受众确定。没有逐智能体记忆配置。暂停学习不关闭明确记忆保存、已有有效记忆读取、对话压缩或来源失效检查；群聊学习不要求 @，也不会向群内发送学习通知。

用户本次不记忆／不学习、协作候选、群聊权限及自动维护规则见记忆与学习职责与运行规则。

外部知识库

  1. 进入「外部知识库」，检查 WeKnora 连接和项目绑定。
  2. 检查项目目录同步、资料解析、索引及当前用户可访问范围。
  3. 确认知识库助手模型可用。资料查询是它的固定职责，不需要逐个勾选知识库授权；其他智能体通过已授权协作调用知识库助手。
  4. 使用有项目和资料权限的业务用户，从工程资料问答入口验证有明确来源的问题。

知识库查询权限与项目数据库交互权限分别配置。管理端调试不能代替真实业务身份验证；平台聊天模型和 WeKnora 生成模型的绑定也需分别核验。

业务接入细节见知识库问答接入说明，模型边界见模型与原生图片输入。

调试与只读审计

保存配置后，从目标智能体打开「调试」并新建会话。检查实际模型回复、所需工具调用、协作结果和失败原因；配置看似完整或模型自称有某能力，都不能代替真实调用结果。涉及项目身份、资料受众和正式业务确认的功能，还须在对应工程平台入口验证。

调试采用隔离测试身份和记忆范围，不借用生产用户身份。会话权限跟随智能体已保存的执行模式；运行进展、自动停止、输出截断及恢复规则见自动运行管理。

查看平台交互审计

  1. 进入「平台交互审计」，先选择具体平台用户。
  2. 选择该用户所属项目，再选择目标会话。
  3. 核对消息、工具调用、时间和状态，定位实际调用及授权链路。

审计页只读，不修改消息、不提供编辑或重放。权限审核记录用于查看审核决定，记忆学习记录用于查看后台处理，它们与用户会话审计承担不同职责。

问题排查

业务端看不到智能体是否为公开业务智能体，是否允许平台运行并发布；内部对象不会进入普通业务目录。
找不到协作目标或派发被拒绝先核对是否试图调用总控／初始化，再检查双方启用、目标对应接收许可和调用方明确名单；不要用旧团队成员身份绕过。

数据库交互无法保存核对名称与技术标识、主表和操作、会话类型、字段选择、绑定及关联别名；表白名单缺失时由平台维护人员处理。
没有可选关联表两表均须在白名单内，当前查询路径须存在真实外键；字段名称相同不构成关联依据。
数据库写入或 MCP 内部数据调用被拒绝检查执行智能体分配、调用方式、真实会话、用户项目范围、字段白名单和权限审核结果。以具体错误码定位，不写死令牌或项目身份绕过。
初始化专家不工作或没有进入核验核对编排技能、专家接收许可和名单、各自分区交互；确认所需分区已保存，主智能体具有提交核验交互，并已选择可用核验版本。
核验规则仍是旧版本上传后是否选择新版本并保存；重新发起核验，历史结果不会自动重跑。
知识库回答没有资料依据核对连接、项目绑定、解析索引和用户资料权限；确认经知识库助手查询，并检查返回来源。
学习未产出或显示等待查看总开关、对应来源和独立学习模型，再看学习记录中的等待／跳过原因。没有价值的材料允许空结果，不要求每批产生记忆。
索引未就绪在运行诊断查看失败与自动重试；正文保存和文字检索独立，索引等待不等于记忆丢失。
保存按钮不可用或出现版本冲突检查是否有未保存变化、是否正在请求及必填校验；冲突时处理最新版本与草稿差异，不反复覆盖提交。
运行提前结束查看最终总结和实际调用是否重复、失败或触发资源保护；不能只增加旧轮次参数，参阅自动运行规则。
