# 智能体运行自动管理

总控、助手、业务智能体、调试及确认后恢复，通过同一 ChatService 应用运行策略。策略仅用于平台运行，不修改通用 SDK 默认行为。

## 配置入口

智能体编辑表单选择模型策略、凭证和模型，不逐个设置输出额度、ReAct 轮次、上下文、结构化输出重试或中断细项。模型参数统一在「模型与连接」保存，详见[统一模型与原生图片输入](统一模型与原生图片输入.md)；压缩模型与记忆设置见[记忆与学习职责与运行规则](记忆与学习职责与运行规则.md)。

调试及聊天的「会话设置」保留备用模型和语音合成选择，不提供会话级模型参数覆盖。固定模型在调试时不可切换。

调试权限跟随「编辑智能体 → 高级设置 → 执行权限模式」，界面只显示当前模式和「随配置」，创建接口拒绝冲突覆盖。旧调试会话、协作成员和恢复运行在执行前重新读取所属智能体的权限模式；会话已有权限规则与任务状态保留。后台计划任务及工程平台会话继续遵循各自的权限配置流程。

## 进展判断与停止条件

有新结果时继续运行，逐智能体保存的旧轮次值不控制平台任务。系统比较每轮工具、规范化参数、结果和任务状态，不额外调用模型判断进展；相同查询返回新结果不视为重复。

| 条件 | 行为 |
| --- | --- |
| 连续 3 轮重复、失败或无输出 | 提示检查结果、调整方法 |
| 连续 6 轮失败，或连续 6 轮重复／无输出 | 结束当前阶段 |
| 单个回复达到 200 轮、100 万输出词元或 1 小时累计活跃时间 | 触发资源保护，保留当前进度 |

批量工具以完整一轮计数，不按并行工具数量计数。等待用户确认不计入活跃运行时间；时间检查发生在轮次边界，不把正在执行的写操作转成后台重放。确定性检测不能识别所有语义上的无效工作，持续变化却无用的结果仍受资源保护限制。

异常结束前允许一次不调用工具的总结，说明完成部分、未完成部分和阻碍。模型仍输出工具调用时关闭这些未执行调用，最终状态为未正常完成，不显示成任务完成。

## 输出截断与阶段保存

已知输出能力的模型按目录额度和当前上下文余量安排输出。未知能力保持为空；接口允许省略长度且没有显式配置时，不发送长度参数。要求长度的接口若既无登记能力也无明确请求值，返回错误，不用固定数字冒充能力。模型输出能力与上下文压缩预算分别处理。

OpenAI Chat 兼容、DeepSeek、Moonshot、DashScope、Anthropic 和 OpenAI Responses 适配器识别输出截断。正文截断时最多连续追加 4 次；工具参数截断时不执行不完整调用，允许重新生成。未接入截断标记的适配器不保证自动续接。

长任务使用服务端运行、事件订阅和取消机制。完成的轮次在下一次模型调用前按至少 30 秒间隔保存，结束或中断时完整保存。刷新页面不要求重放已执行工具；检查点不承诺服务器崩溃后自动重做任务，有副作用的调用不因恢复而无条件重试。
