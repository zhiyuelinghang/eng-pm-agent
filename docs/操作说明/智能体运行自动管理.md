# 智能体运行自动管理

更新日期：2026-09-10。

## 管理入口

主智能体与业务智能体共用编辑表单。模型配置只选择模型策略、模型凭证和模型；不再逐个配置输出 Token、ReAct 轮次、上下文、结构化输出重试、中断文案或取消异常。

「模型与连接」只保留思考设置和必要的服务商接口扩展入口，不再展示输出额度、采样、并行请求与思考预算等细项；添加或修改模型身份也不再重复配置接口扩展。已有显式参数不会因界面精简而被清空。旧智能体与会话的参数覆盖在平台运行时不再采用，原记录不会被启动程序改写，也不会自动迁移到共享配置。编辑保存时只保存模型选择。权限、职责和工具分配继续单独生效。

调试与聊天中的「会话设置」保留备用模型、语音合成选择，不再提供单个会话的模型参数覆盖。固定模型在调试时仍不可切换。

调试权限同样跟随「编辑智能体 → 高级设置 → 执行权限模式」。界面只显示当前模式和「随配置」，不提供会话切换；创建接口自动采用已保存的配置，并拒绝冲突的权限覆盖。旧调试会话、协同成员和恢复运行在每次执行前重新读取所属智能体的权限模式，保留会话内已有的权限规则与任务状态。后台计划任务及工程平台会话仍遵循各自原有的权限配置流程。

## 系统运行策略

- 总控、助手、业务智能体、调试和确认后恢复，通过同一 ChatService 应用策略。
- 任务有新结果时继续运行，旧记录中的 20 轮或其他逐智能体轮次不再控制平台任务。
- 不调用额外模型判断进展。系统比较每轮的工具、规范化参数、结果及任务状态，识别重复查询和交替重复操作。相同查询返回了新结果，不视为重复。
- 连续 3 轮重复、失败或无输出时提示调整方法；连续 6 轮失败、6 轮重复或无输出时结束本阶段。批量工具以完整一轮计数，不以单个并行调用计数。
- 结束前允许一次不调用工具的总结，说明完成部分、未完成部分和阻碍。模型仍输出工具调用时，系统会关闭这些未执行调用。最终状态为未正常完成，不伪装为任务完成。
- 平台保留紧急保护：每个回复最多 200 轮、100 万输出 Token、1 小时累计活跃时间；这不是普通任务的完成标准。时间检查发生在执行轮次边界，不会因为等待用户授权而超时，也不会按计时器把正在执行的写操作转成后台重放。

这些检测是确定性信号，不保证能判断所有语义上的无效工作；持续变化的无用结果仍由资源保护兜底。

## 输出与长任务

已知输出能力的模型按目录额度和当前上下文余量安排输出。发现或手动添加模型时，未知的输出能力记为空，不再填入 8192。对于可省略输出长度的接口，未显式指定且能力未知时不发送长度参数，由模型服务决定。厂商决定的长度不保证是其允许的最大值，也不代表无限输出。

要求必须提供输出长度的接口仍按其协议处理：已知目录能力或明确的请求长度可用于调用；两者均未知时给出明确错误，不以另一个固定数字冒充模型能力。上下文压缩使用的工作预算与模型输出能力是两件事，本次不改变上下文压缩策略。

OpenAI Chat 兼容、DeepSeek、Moonshot、DashScope、Anthropic 和 OpenAI Responses 已接入输出截断标记。正文被截断时自动接续，最多连续追加 4 次；工具参数被截断时不会执行，允许重新生成完整参数。能力未接入的适配器不承诺自动续接。

长任务沿用现有服务端运行、事件订阅和取消机制。完成的轮次在下一次模型调用开始时按至少 30 秒间隔保存，结束或中断时仍完整保存。刷新页面不会要求重放已执行工具。此检查点机制不等于服务器崩溃后自动重做任务，存在副作用的调用不会因为恢复流程被无条件重试。

## 实现与验证

- `AgentScope/agentscope/agent/_execution.py`：统一执行策略和可持久化计数。
- `AgentScope/agentscope/app/_service/_chat.py`：平台入口统一应用，不修改通用 SDK 默认行为。
- `AgentScope/agentscope/app/middleware/_managed_model_middleware.py`：模型输出额度适配。
- `AgentScope/agentscope/app/_service/_run_checkpoint.py`：活跃任务的阶段性保存。
- `AgentScope/tests/test_managed_execution.py`：超过 20 轮、重复及交替循环、连续失败、确认等待、截断续接、截断工具安全、阶段保存和模型参数继承测试。

2026-09-09 验证结果：145 项后台回归、15 项前端测试及前端构建通过。在真实本地管理页面打开总控编辑与调试窗口，确认配置项已简化；独立调试会话使用原有 DeepSeek V4 Flash 配置，成功返回「连接正常」。长循环与异常路径通过可控模型回归验证，未在真实模型上反复执行工具。

2026-09-10 输出能力修正：62 项模型目录与运行测试、16 项迁移测试通过。清理现有 `deepseek-flash` 与 `deepseek-v4-pro` 的目录假定值后，运行中的目录 API 均返回未知输出能力，参数 schema 不再带 8192 上限；两者也不存在额外保存的长度覆盖。再次迁移预览为零条。请求省略与必填接口行为通过模拟 SDK 验证，未发送真实模型推理请求。

2026-09-10 的输出能力修正不增加数据库表或字段。存量动态聊天模型中曾自动填入的 8192，通过 `scripts/remove_assumed_model_output_limits.py` 显式预览和一次性清理为未知；其它已登记额度、嵌入模型以及用户显式请求参数保持不变。程序启动时不执行兼容转换。
