# 统一模型与原生图片输入

## 模型配置与继承

可用模型以管理端「模型与连接」中当前保存的凭证、目录和启用状态为准。文档不指定某个环境的模型名称或绑定对象。

思考模式、思考强度及接口扩展在模型目录统一保存。正式运行、模型测试、调试和协同调用读取已保存参数，未保存的页面草稿不参与请求。智能体与会话只承担模型选择，旧局部参数覆盖不控制运行，也不会被启动程序自动转换为共享配置。

协同邀请、再次派发、创建下级智能体和计划任务读取调用者当前有效模型；目标自身配置固定模型时，固定策略优先。已删除、未登记、停用或凭证不匹配的固定模型在保存、创建或运行时明确报错，不悄悄替换。

业务资料补全通过平台共享文本服务读取总控当前固定模型和共享参数，不维护另一套 `AI_MODEL`、`AI_BASE_URL`、`AI_API_KEY`。此入口仅供受信的平台后端调用，不创建智能体会话、执行工具或记录记忆。

学习、对话压缩和权限审核保留各自明确的模型配置，规则分别见[记忆与学习职责与运行规则](记忆与学习职责与运行规则.md)和[智能体分工与协作规则](智能体分工与协作规则.md)。向量嵌入、重排、语音和资料解析 VLM 属于独立用途。

模型输出长度与截断处理见[智能体运行自动管理](智能体运行自动管理.md)。

## 原生图片输入

只对模型目录确认支持的图片类型启用原图输入，不能仅依据模型名称假定支持。已确认的手动能力定义在刷新发现目录后继续保留。

- 管理端上传的受支持图片保留原图，通过模型接口图片内容块发送。
- 工程平台首页、助手及业务智能体会话发送本轮选择的原图，资料上传引用继续保留。
- 项目初始化仅读取当前项目、当前初始化会话中所选文件的原图；成功解析的文字可附带，文字解析失败不丢弃有效原图。
- 工程平台每轮最多 8 张、合计 30 MB；后端验证真实格式、损坏或截断文件、大小和来源范围，再与模型图片能力匹配。
- 普通文档使用附件解析；群聊使用专用上传与资料授权流程。

## 外部知识库模型

知识库助手会调用 WeKnora 问答服务，其生成模型绑定须在 WeKnora 中单独核验。平台聊天模型选择不代表远端问答、知识库摘要或 Wiki 模型已经同步变更；不能从模型 ID 猜测名称，也不能将接口访问失败当成模型已对齐。
