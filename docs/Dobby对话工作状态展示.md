# Dobby 用户对话工作状态展示

用户聊天按原顺序保留思考过程、每条调用记录和回答。思考正在生成时自动展开，结束后默认收起，用户可随时展开查看；历史记录同样可查看。调用记录展示中文工作描述和真实状态，例如“查看项目人员”“保存记忆”；隐藏函数名称、调用参数及原始返回值，未知操作使用“处理相关事项”。协同调用及下级工作记录也保留，但不复制协同任务参数。顶部工作提示只是补充，不替代逐条记录。完成后仍展示助手正文、表格、图片和结果文件。

业务操作需要确认时，展示服务端提供的变更对象、影响和修改前后内容，保留原有回复标识及确认版本。没有可读的影响预览时不允许盲目确认，用户仍可拒绝。旁观者仅查看；停止后或停止过程中不再保留可执行的确认按钮。

没有可展示结果时明确说明；失败显示简洁提示，不把错误堆栈或原始返回值放进聊天。实时和历史对话统一使用这些展示规则，诊断记录本身不改写。工具结果没有统一的业务展示协议，因此不直接复制其输出；可读结果由既有助手答复与附件承载。

验证：更新展示回归测试，覆盖思考展开与收起、调用顺序、重复调用、成功与失败状态、历史记录以及业务确认。

## 工作描述来源（2026-09-08）

业务前端不再维护工具名称翻译表，也不根据函数名、参数、SQL 或返回值猜测工作内容。工具注册信息统一生成 `presentation = {label, source, category}`，执行状态独立来自实际事件。

- 普通工具：在 ToolBase 子类上声明 `display_name`；FunctionTool 注册时可传入 `display_name="核对设备清单"`。系统文件工具、协同工具、知识库及当前记忆工具已接入。
- MCP：运行适配器与管理目录均读取 `Tool.title`，缺失时读取 `annotations.title`。更新 MCP 包标题后，新调用自动使用新值。
- 数据库：使用数据库交互目录的 `display_name`，与管理端现有业务名称共用，不采用表名或 SQL。
- 未提供有效标题：按已知来源、只读属性使用“查询业务数据”“处理外部事项”等通用提示。描述仅用于展示，不参与权限判断。工具长描述、技术标识及明显无效标题不作为展示标题。

工具目录原有查询完成后，Toolkit 同步建立本次模型调用的展示快照。输出工具开始事件时只读取内存，不额外调用模型、发现 MCP 工具或访问数据库。模型生成的同名展示字段不会覆盖注册信息。

`TOOL_CALL_START.presentation` 写入 `ToolCallBlock.presentation`，随原有消息 JSON 保存；协同开始和结束进度也携带相同快照。用户前端直接消费，不随工具改名或卸载重算过去的文案。旧记录缺少快照或只有通用描述时，读取页面时根据当前工具注册、MCP 缓存目录和数据库业务目录补齐展示文案，标记为 catalog_backfill。保留已有真实快照，不改写原始消息、参数及执行结果。无法识别或同名来源存在歧义时才继续使用通用描述。本次无需数据库表结构迁移。

管理端工具详情与 MCP 详情显示实际用户文案及来源。数据库交互编辑页说明业务名称的用户展示用途，并显示服务端当前预览。普通工具文案在注册处配置，MCP 文案在包标题配置；不额外维护一份前端名称目录。

验证：后端注册、事件、历史快照、MCP、数据库、工作区权限与运行回归测试；用户前端思考、逐条调用、历史恢复及新工具展示测试；两套前端构建。生效需重新加载 AgentScope 服务并更新前端，新调用才会产生展示快照。

补齐既有工具：计划、定时安排、技能查看、后台停止及其余协同操作均在注册位置补充文案。旧消息和协同记录按上述兼容规则展示；目录按登录用户与智能体隔离缓存 60 秒，单次解析最多等待 2 秒，目录故障不阻断历史读取。模型完整响应写入执行上下文时也保留注册快照，确保待确认与恢复流程携带同一描述。

### 记忆记录冷启动修复

旧实现通过 `sys.modules` 判断记忆运行模块是否已加载，导致服务重启后直接打开旧对话时，记忆工具目录为空。此前测试导入 `_direct` 后才检查历史，未覆盖此路径。

记忆标题现统一声明在轻量的 `memory/_tool_metadata.py`，运行注册与历史补齐直接共用，完全不依赖 `_direct` 模块的加载时机；旧名称 memory_search、memory_read、memory_write 仅作为历史展示别名。冷启动历史查询不调用记忆服务、模型或远程目录。

新增嵌入式 Python 全新进程测试：只加载历史接口，直接读取模拟的旧记忆记录，断言运行模块始终未加载、无需目录查询且原始记录未被修改。将该接口实际输出保存为前端测试夹具，再由真实聊天组件渲染并验证“查找记忆／保存记忆／读取记忆”；本地浏览器同样验证通过。本轮后端 43 项、前端 50 项测试通过。

记忆展示文案调整：查找、读取记忆统一显示“回顾相关信息”，保存记忆显示“记下重要信息”。仅调整这两类记忆动作的展示标题，其他工具及数据库交互名称不变。
